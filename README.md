# State of Data Brazil

O **State of Data Brazil** é o maior mapeamento do mercado de trabalho em dados e IA no
Brasil. Desde 2019, a pesquisa pergunta a milhares de profissionais sobre salário,
cargo, senioridade, formação, modelo de trabalho, tecnologias, uso de IA generativa e
diversidade.

Este repositório reúne **as 6 edições publicadas**, com 22.686 respostas somando todos os
anos, e as colunas **harmonizadas entre as edições**: a mesma pergunta pode ter nomes e opções diferentes em cada edição, e aqui isso
já está resolvido. Junto vêm funções prontas para salário em faixas e correção pela
inflação, e a skill **`/state-of-data-analyst`**, para quem quiser explorar os dados
conversando com Claude Code, Codex ou Claude pelo navegador.

## 📋 Sobre a pesquisa

O questionário é online e fica aberto entre outubro e dezembro de cada ano. É divulgado
pela comunidade Data Hackers e por parceiros. Responde quem trabalha, estuda ou quer
trabalhar com dados no Brasil.

<details open>
<summary><strong>O que a pesquisa pergunta</strong></summary>
<br />

A partir de 2021, o questionário é dividido em 8 partes:

| Parte | Tema |
|---|---|
| 1 | Dados demográficos: idade, gênero, cor/raça, PCD, estado, formação |
| 2 | Carreira: situação de trabalho, setor, cargo, nível, salário, satisfação, modelo de trabalho |
| 3 | Desafios de quem lidera times de dados |
| 4 | Conhecimentos na área: fontes de dados, linguagens, bancos, cloud, BI, IA generativa |
| 5 | Objetivos na área de dados |
| 6 | Rotina e ferramentas de Engenharia de Dados |
| 7 | Rotina e ferramentas de Análise de Dados |
| 8 | Rotina, técnicas e ferramentas de Ciência de Dados |

A edição de 2019 usou um questionário mais curto e diferente. A de 2021 teve uma 9ª parte
sobre a comunidade Data Hackers.

</details>

<details>
<summary><strong>Como os dados são anonimizados</strong></summary>
<br />

Antes da publicação, a Data Hackers anonimiza as respostas para que ninguém possa ser
identificado:

- respostas muito fora do padrão (outliers) que poderiam identificar alguém são removidas ou transformadas;
- estados com poucas respostas aparecem só com a região (por exemplo, alguns estados do Norte);
- algumas perguntas foram retiradas do dataset público.

Por isso, nem tudo o que foi coletado está no dataset público.

</details>

## 🚀 Como usar

### Com um agente de IA (Claude Code, Codex e outros)

Para uso local, você precisa de um agente como o [Claude Code](https://claude.com/claude-code)
ou o [Codex](https://github.com/openai/codex), e de Python 3.9 ou mais recente. Para uso
no navegador, veja a opção 5. Os dados vêm do próprio repositório: **não é preciso
conta nem token do Kaggle**.

#### Opção 1: instalar como plugin do Claude Code

Funciona em qualquer pasta, sem clonar o repositório:

```bash
claude plugin marketplace add data-hackers-br/state-of-data-brazil
claude plugin install state-of-data-brazil@data-hackers
```

Depois, em qualquer sessão do Claude Code:

```
/state-of-data-brazil:state-of-data-analyst como evoluiu o salário de cientistas de dados por nível desde 2021?
```

Na primeira análise, a skill cria um ambiente Python próprio (pandas, numpy e pyyaml) em
`~/.claude/plugins/data/`. Para receber versões novas: `claude plugin update state-of-data-brazil@data-hackers`.

#### Opção 2: instalar com `npx skills`

O [`skills`](https://github.com/vercel-labs/skills) é um instalador de skills que funciona
com Claude Code, Codex, Cursor, GitHub Copilot e outros agentes. Precisa do Node.js:

```bash
npx skills add data-hackers-br/state-of-data-brazil
```

Com chave SSH configurada no GitHub, também funciona assim:

```bash
npx skills add git@github.com:data-hackers-br/state-of-data-brazil.git
```

O instalador pergunta para quais agentes instalar e se a skill vale só para o projeto
atual ou para todos (`-g`). Ele copia apenas a pasta da skill. Por isso, na primeira
análise, a skill baixa uma cópia do repositório público (cerca de 80 MB, uma única vez)
em `~/.cache/state-of-data-brazil` e cria ali o ambiente Python. Para atualizar os dados:
`git -C ~/.cache/state-of-data-brazil pull`.

#### Opção 3: usar no Codex

Instale a skill para o Codex com o mesmo instalador, para todos os seus projetos:

```bash
npx skills add data-hackers-br/state-of-data-brazil -a codex -g
```

Ela fica em `~/.agents/skills/state-of-data-analyst/`, onde o Codex procura skills. Sem
o Node.js, dá para copiar essa pasta manualmente do repositório
(`.claude/skills/state-of-data-analyst/`) para `~/.agents/skills/`.

No Codex, chame a skill pelo nome ou só faça a pergunta: o Codex escolhe a skill quando o
assunto bate com a descrição dela.

```
$state-of-data-analyst como evoluiu o salário de cientistas de dados por nível desde 2021?
```

Na primeira análise, a skill precisa de acesso à rede para baixar os dados e as
dependências que faltarem. Se o ambiente estiver sem rede, você pode fornecer o
repositório completo já baixado e um Python com as dependências de `requirements.txt`
instaladas. A skill reutiliza essa cópia local.

#### Opção 4: clonar o repositório

Melhor se você quiser ver o código, mexer no mapeamento ou contribuir:

```bash
git clone https://github.com/data-hackers-br/state-of-data-brazil.git
cd state-of-data-brazil
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
claude
```

Dentro do Claude Code, na pasta do repositório, chame a skill com a sua pergunta:

```
/state-of-data-analyst como evoluiu o salário de cientistas de dados por nível desde 2021?
/state-of-data-analyst mulheres e homens com a mesma experiência ganham o mesmo?
/state-of-data-analyst quais linguagens cresceram mais entre analistas de dados?
/state-of-data-analyst engenheiros de dados estão voltando ao presencial?
```

A skill lê os dados locais, usa o mapeamento de colunas entre edições e as funções de
`scripts/sod/`, e responde com os números, o tamanho de cada amostra e as ressalvas de
metodologia.

O clone já contém a skill em `.claude/skills/`, reconhecida pelo Claude Code. Para
usá-la no Codex, faça também a instalação da opção 3; clonar o repositório, por si só,
não instala a skill no catálogo do Codex.

#### Opção 5: usar no Claude pelo navegador

Quando sua conta oferecer importação de skills e execução de código Python:

1. Baixe o arquivo [`SKILL.md`](https://raw.githubusercontent.com/data-hackers-br/state-of-data-brazil/main/.claude/skills/state-of-data-analyst/SKILL.md).
2. Nas configurações de personalização do Claude, importe o arquivo na área de
   skills e ative `state-of-data-analyst`.
3. Abra uma conversa e peça uma análise usando a skill. Se o ambiente de execução
   não conseguir acessar o GitHub, baixe o [ZIP do repositório](https://github.com/data-hackers-br/state-of-data-brazil/archive/refs/heads/main.zip)
   pelo seu navegador e anexe-o à conversa. A skill usará os arquivos extraídos.

Exemplo com o ZIP anexado:

```text
Use a skill state-of-data-analyst e o repositório ZIP anexado para comparar o salário
real de Júnior e Sênior em 2021 e 2025/26. Informe os tamanhos das amostras e as
ressalvas de comparação. Gere um gráfico PNG para download.
```

O ZIP inclui os dados e o código, mas as bibliotecas Python ainda precisam estar
disponíveis no ambiente. A skill verifica as dependências antes de analisar. A skill
`dataviz` é opcional; sem ela, os gráficos podem ser feitos com Matplotlib, que já
consta em `requirements.txt`.

### Sem agente de IA

A base harmonizada é um CSV comum, com uma linha por respondente:

```python
import pandas as pd

df = pd.read_csv("data/harmonized/state_of_data_harmonized.csv", low_memory=False)
df.groupby("ano").nivel.value_counts(normalize=True)
```

O salário vem em faixas (por exemplo, "de R$ 8.001/mês a R$ 12.000/mês"). Para calcular
medianas e corrigir pela inflação, use as funções prontas:

```python
import sys; sys.path.insert(0, "scripts")
from harmonize import build
from sod import stats

df = build()
sr = df[(df.ano == "2025/26") & (df.nivel == "Sênior")]
stats.median(sr)                      # mediana interpolada dentro das faixas, em R$
stats.deflator("2021")                # fator para levar R$ de 2021 a R$ de nov/2025
```

## ⚠️ Cuidados ao comparar edições

As perguntas e as opções de resposta mudam de uma edição para outra. A lista completa
está em [`mapping/schema_map.yaml`](mapping/schema_map.yaml); os pontos mais importantes:

- **A amostra não é aleatória.** São as pessoas que responderam à pesquisa, e o perfil muda a cada ano (por exemplo, cada vez menos juniores). Compare dentro de grupos (nível, experiência) antes de tirar conclusões sobre o mercado.
- **O salário vem em faixas**, e a mais alta ("acima de R$ 40k") não tem teto.
- **2019 usou outro questionário:** não tem nível Júnior/Pleno/Sênior, e a faixa salarial vai só até R$ 25k. Gênero, estado, formação, cargo, experiência, linguagens, cloud e BI são comparáveis; região também, mas 2019 só identifica Sudeste e Sul.
- **Especialista/Staff+** existe só a partir de 2025/26 e tira do grupo Sênior parte das pessoas mais bem pagas.
- **Correções nos dados:** em 2023, as colunas de cloud estão com os rótulos trocados; em 2022, as colunas binárias de cloud registram a cloud preferida, não a usada. As funções de `scripts/sod/` já tratam esses casos.

## 🌎 English summary

Open data from the **State of Data Brazil**, the largest survey of the data and AI job
market in Brazil, run by [Data Hackers](https://datahackers.com.br) in partnership with
[Bain & Company](https://www.bain.com) (since 2021). It covers 6 editions (2019 to 2025/26)
and 22,686 responses summed across editions, with columns harmonized across editions. It ships with a
[Claude Code](https://claude.com/claude-code) skill (`/state-of-data-analyst`) that
answers questions across years. The skill handles salary bands, inflation adjustment
(IPCA) and known data quirks. To use it, clone the repo, run `pip install -r requirements.txt`,
open `claude` in the folder and ask. The survey questions and data are in Portuguese.
